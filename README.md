# mptv-schedule — единая программа MPTV

Единая программа передач для **всех** устройств MyPersonalTV (Android-приложение
MPTVCOLLAPS, веб, MSX-ТВ). Собирается **один раз в неделю** (логика `msx-8`,
репа [MPTVMSX-web](https://github.com/mycartooncatstory-netizen/MPTVMSX-web),
скрипт `msx/build-unified.ts`) и публикуется сюда. Устройства читают
raw-ссылки — программу у всех одна и та же.

## Файлы

| Файл | Назначение |
|---|---|
| `index.json` | Список недель. Клиент берёт **последнюю неделю, у которой `effectiveFromMs` ≤ сейчас** |
| `weeks/<понедельник>.json` | Плейлисты 12 каналов одной недели (60 фильмов жанровые/VHS/Новинки, 30 — «Русское кино») |
| `state.json` | Ротация (consumed): фильмы не повторяются в эфире 30 дней — состояние для следующей сборки |

Неделя вступает в силу **в понедельник 16:00 Asia/Yekaterinburg** — это граница
эфирного дня (16:00–04:00 премьеры, 04:00–16:00 повторы). Сетку эфира каждое
устройство считает само из плейлиста (алгоритм один и тот же — «3 дня назад
16:00, день ≥6 фильмов и ≥12 ч»), поэтому у всех эфир совпадает с точностью
до секунды.

**История неприкосновенна**: прошедшие недели не изменяются, текущая неделя
не пересобирается.

## Формат недели

```jsonc
{
  "schema": 1,
  "weekId": "2026-11-23",              // понедельник недели
  "effectiveFromMs": 1795431600000,    // пн 16:00 Asia/Yekaterinburg
  "logicVersion": "msx-8",
  "tz": "Asia/Yekaterinburg",
  "channels": {
    "fantastika": { "name": "Фантастика", "category": "Кино", "items": [
      { "dedupKey": "kp:123", "tid": "456", "kpId": "123", "imdbId": "tt…",
        "title": "Название (год)", "year": 2001, "poster": "https://…",
        "durationMs": 6420000, "description": "…", "metaInfo": "IMDB:…|KP:…|TID:…",
        "genres": "[\"Фантастика\"]" }
    ]}
    // … 12 каналов: fantastika fentezi priklyucheniya komedii uzhasy boevik
    //   detektiv vhs novinki ru-komediya ru-drama ru-kriminal
  }
}
```

Правила наполнения — см. `msx/channels.ts` (RATING) и `msx/rebuild.ts` в репе
MPTVMSX-web: пол рейтинга 6.0, Россия/СССР в жанровых ≥7.0, нишевые страны
≥7.0 + потолок 9/60, класс-квота 1930–84 (≤4 с КП ≥7.5 + ≤2 с КП ≥8.0),
30-дневная ротация, фильтр рекламы и отсутствие русской озвучки, выметание
мёртвых стримов.
